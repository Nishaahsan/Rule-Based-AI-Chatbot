# Rule-Based AI Chatbot
A professional, production-ready **Rule-Based AI Chatbot** built with deterministic logic and hash map architecture. This project demonstrates foundational AI concepts through explicit rule-based decision making.

# Project Overview

This chatbot implements the **Deterministic White Box** approach from DecodeLabs Industrial Training Kit. Instead of probabilistic responses (like ChatGPT), every input maps directly to a predefined output - 100% predictable, traceable, and hallucination-free.

# Key Features

- ✅ **O(1) Constant-Time Lookups** using Hash Map/Dictionary architecture
- ✅ **Zero Hallucination Risk** - Every response is hard-coded and predictable
- ✅ **Input Sanitization** - Handles case sensitivity, whitespace, and punctuation
- ✅ **Professional Fallback System** - Graceful handling of unknown inputs
- ✅ **10+ Predefined Intents** - Greetings, questions, jokes, educational content
- ✅ **Continuous Loop** - Runs until exit command (bye/quit/exit)
